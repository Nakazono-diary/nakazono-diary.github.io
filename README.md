# 日記・タイムライン(個人用)

ボタンで記録する、自分だけの1日のタイムライン。仕様は Claude プロジェクト「自己作業管理」の `specs/20_日記タイムラインアプリ仕様.md`。
大和設計の共有タスク管理(task-app)とは別アプリ・別データ。

## 今できること(v0.13.0)

- ボタンは3つのタブ: 1日の流れ(起床・出発・到着・出社・退社・帰宅・就寝・食事)/すること(昼休み・休憩・再開・読書・テレビ・ゲーム・趣味・フィットネス)/用事(病院・お墓参り・買い物・銀行・役所・床屋)。押した時刻で記録され、今日のタイムラインに並ぶ
- 「ボタン設定」: ボタンを足す・名前と絵を変える・並べ替える・タブを変える・消す・押したら移動手段を聞くか
- 「作業」ボタン: タスク管理から読み込んだ件名リストで、件名と工程を選んで記録できる(バックアップ画面の「タスク管理の件名リスト」から読み込む。件名と工程の名前だけ)
- 押した直後の「書き足す」「取り消す」
- 「書く(文章・写真)」: 長い文章と写真を、メモまたはボタンの種類で記録。時刻も変えられる。書きかけは自動で取っておく
- 移動手段(徒歩・走る・泳ぐ・自転車・バイク・車・電車・地下鉄・新幹線・リニア・バス・タクシー・船・飛行機・その他)を、いくつでも押した順に付けられる。「出発」「退社」の直後にその場で選べる
- カードの「直す」: 時刻・種類・文章・写真を直す、消す
- 写真は小さくして(長い辺 1600px)スマホの中にしまう。撮影場所などの情報は消える
- 右上の「バックアップ」: 記録を文章・写真ごと JSON ファイルに書き出す/そのファイルから読み込む(今ある記録は消さずに足す。機種変更・ミニPCへ移すとき用)
- iPhone でホーム画面に入れていないときは「ホーム画面に入れてください」と出す
- 電波がなくても開ける(アプリのファイルをスマホにしまう)
- 乗りかえ(v0.10): 出発・退社のあと、最初の移動手段を選ぶ。移動中は下の帯に移動手段が並び、乗りかえたら押す。カードは「🚶 徒歩 6分 → 🚃 電車 22分 → 🚶 徒歩 7分」。直す画面で乗りかえの時刻を直す・足す・消す。押した直後の欄で2回目に押しても乗りかえになる。選んでから1分以内に押し直すと、押しまちがいとして入れかわる(v0.10.1)
- 外出・移動(v0.11。タブ「外出・移動」): 外出(仕事の途中や昼食を買いに出るとき。戻り・帰宅で終わる。勤務は続いたまま)、戻り、移動(移動だけの記録。移動手段と乗りかえ。到着・出社・帰宅・戻りで終わる)
- 前の日を見る(v0.12): 上の「◀ 前の日・日付・次の日 ▶・今日へ」。前の日を見ているときに「書く」と、その日に入る。Surface など広い画面では、左にその日の記録と「1日の流れ」の帯、右にボタン(← → キーでも日を動かせる)
- 同期(v0.13): 足もとの「☁ 同期」で、スマホと Surface の記録を合わせる。中身はこの端末で合言葉の鍵をかけてから、グーグルドライブのアプリ専用の隠しフォルダに置く(Google にも読めない)。消した記録はほかの端末からも消える。合言葉を忘れるとドライブの分は開けないので控えておく
- 統計(v0.10。右上の「統計」): 今週・今月・今年・全部で、移動手段ごとの合計・回数・平均、通勤(出発→出社)の平均、睡眠(平均・寝た時刻と起きた時刻の平均・最近の睡眠)、食事(1回の平均・1日あたりの回数・朝昼夜の平均)。仕事の時間はタスク管理で見るので入れない
- 時間の長さ(v0.9):
  - 食事・作業・休憩・昼休み・読書・テレビ・ゲーム・趣味・フィットネス・用事・就寝・出発・出社・退社は、押すと「始まり」。下に「続いているもの」の帯が出て、「終わった」を押す(同じボタンをもう一度押しても終わる)と「12:05〜12:40 食事(35分)」になる
  - 組になっているものは自動で終わる: 就寝→起床(睡眠)、出社→退社(勤務)、出発・退社→到着・出社・帰宅(移動)、昼休み・休憩→再開
  - 書く・直す画面で、始まりと終わりの時刻をあとから直せる。半日以上続いているものは「終わり忘れ?」と出す
  - どのボタンを長さにするかは、ボタン設定の「時間の長さを記録する(終わりも押す)」。前からある記録は時刻だけのまま
- 場所(v0.8):
  - 起床・出発・到着・出社・退社・帰宅と、用事のボタンを押すと、スマホがいまの位置を測る(ボタン設定の「押したら場所を測る」で変えられる)
  - 名前を付けた場所の近く(はじめは半径150m)なら、その名前が自動で付く(📍 大和設計 など)。登録していない場所なら、その場で名前を付けられる
  - 書く・直す画面で、登録した場所から選ぶ・測り直す・位置を外す
  - 右上の「場所」で、名前・住所(自分で書く)・範囲を直す、消す、いまの場所を登録する
  - 位置はスマホの中だけ。地図や住所を調べるサービスには送らない(地図も出さない)
- 体調・天気は専用の短い画面(v0.8.1): 気分・お通じ(天気は空模様・体感・いまの気温)だけ最初から出し、体温・血圧・体重・睡眠・お薬・気になること(天気は最高・最低・湿度)は押すと開く(開いた項目は次から開いて出る)。数字は「−」「＋」で、空のときに押すと前回の値から始まる。長押しで速く進む。ひとことは「＋ ひとこと書く」、写真・場所は「写真・場所なども付ける」
- 「体調・天気」タブ(v0.7):
  - 体調: 気分(5段階)・体温・体重・血圧・脈拍・睡眠(時間と深さ)・お薬(自分で登録)・気になること(自分で登録)・お通じ(回数とかたさ)。入れたものだけ記録し、病気かどうかの判断はしない
  - お通じ: 押した時刻で記録し、その場でかたさ(かたい/ふつう/やわらかい)を選ぶ
  - 天気: 空模様(押した順。晴れ → 雨 など)・いまの気温・最高・最低・湿度・体感(暑い〜寒いの5段階)。手で入れる(外から取らない)
- 録音(v0.7): 下の「録音」か、書く画面の「録音する」。声はスマホの中だけ。文字にするのは、ミニPCに移ってから(Whisper)
- 今日の暦(v0.7。上の欄、押すとくわしく): 六曜・旧暦・二十四節気・月齢と満ち欠け・潮回り(大潮など)・吉日(天赦日・一粒万倍日・大明日・寅の日・巳の日・甲子の日、注意の不成就日)・黄道(黄道吉日の十二神)・黄道十二星座・祝日・今日は何の日。すべてスマホの中で計算(`koyomi.js`、何の日の一覧は `kinenbi.js`)
- 潮位: 気象庁の「潮位表」の港ごとのテキスト(1年分)を「バックアップ」から読み込むと、満潮・干潮の時刻と1日の潮位の線が出る。年に1回、翌年の分を読み込む

## 守ること

1. **記録はスマホの中だけ**(IndexedDB)。よそのサイトから何も読み込まない、どこにも送らない、解析の道具を入れない。
   `index.html` の Content-Security-Policy で、この住所以外への通信を止めている。
2. 置き場を替えるときは `store.js` だけを差し替える(画面は `app.js`)。替えた先には暗号化して置く。
3. 位置の履歴(第2段階)は、外のサービス(住所を調べる・地図)に送らない。
4. ファイルの指し方はすべて相対パス(`./`)。どの住所・番号に置いても、そのまま動く。
5. 部品(ライブラリ)は使わない。ビルドもいらない。ファイルを置くだけで動く。

## 置き場所

### いま: GitHub Pages(組織の住所)

建工の体験版(`nakaznoisamu.github.io`)とは別の住所にする。ブラウザの記録は住所ごとにしまわれるので、
同じ住所だと、片方の記録を消したときに日記も消える。

1. GitHub で組織を作る: 右上の「＋」→「New organization」→「Free」→ 組織の名前(例: `ikkun-nikki`)。
   住所は `https://組織の名前.github.io/` になる。
2. 組織の中にリポジトリを作る: 名前は **`組織の名前.github.io` ちょうど**、Public、何も足さずに作る。
   (公開になるのはプログラムだけ。日記の中身はスマホから出ないので、公開されない)
3. このフォルダのファイルを、そのリポジトリの main に置く。
4. リポジトリの Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save。
   数分で `https://組織の名前.github.io/` が開ける。
5. スマホで開いて、ホーム画面に入れる。
   - Android(Chrome): 右上の「︙」→「ホーム画面に追加」または「アプリをインストール」
   - iPhone(Safari): 共有 →「ホーム画面に追加」

### あとで: 自宅のミニPC(Tailscale 経由)

- 置き場所は `/srv/diary`(利用者 `diary`)。建工の `/srv/kenkou` には触らない。
- 待ち受けは `127.0.0.1:8400`、入口は Tailscale の **8444 番**(`tailscale serve --bg --https=8444 http://127.0.0.1:8400`)。
- 建工がミニPCで使っている番号(8000・8099・8100・8200・Tailscale の 443・8443)とはぶつけない(2026-11-02 建工アプリ側のクラ君から。8200 は建工の練習用の門番 kenkou-practice が使用中)。
- 移すのは、建工の宿題(通報メールなど)が片付いてから、本人と相談して決める。それまでは GitHub Pages のまま。
  建工の 443 番は使わない。`tailscale serve --https=443 off` / `reset` / `funnel` は打たない。
- Tailscale のアクセス制限で、8444 番は本人のスマホと Surface だけに許可する。
- 住所が変わるとブラウザの記録は引き継がれない。移る前に「ファイルに書き出す」で保存し、新しい住所で読み込む
  (v0.3 で読み込みができるようになった)。

## 動かしてみる(PC)

```
python -m http.server 8420 --bind 127.0.0.1
```
→ `http://127.0.0.1:8420/` を開く(スマホの大きさにするには、ブラウザの開発ツールで端末の表示にする)。
